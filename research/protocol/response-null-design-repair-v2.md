## Activity, dose, and fair controls

Use evoked activity to prevent a large edited-edge count from being supplied by constant/DC-active sources. For development checkpoint m, compute the original gray-input trajectory with the same explicit initial state, timing and integration length as the development clips. Define source feature a_s as concatenated original ReLU activity over the fixed unlabelled development clips, minus the corresponding gray trajectory. Define beta_s = RMS(a_s). For edge e, development evoked mass is |w_e| beta_source(e). Active dose is the sum of this mass over distinct changed original edges divided by its sum over **all original edges**. Also report the eligible-pool denominator and eligible/whole mass ratio. A zero/unstable whole mass blocks the assay. A DC-based dose is a secondary diagnostic only.

For transferred masks, freeze both edge identities and dose selected on the source development checkpoint. Report receiving-checkpoint evoked mass retrospectively without selecting or repairing the mask from receiving-query responses. Within-model constructions and cross-model transfer answer different questions and must have separate tables.

The legal group key contains source/target type and every effective-edge parameter's shared group identity, rather than a floating-point equality discovered in one checkpoint. Target swaps retain those edge-carried assignments. Exclude original self-loop edges and reject new self-loops, pre-existing edges, duplicate endpoints and repeated edited edges within a mask, preserving the original self-loop count. Report any original parallel edges and fail closed if the implemented constructor only supports a simple directed graph. Verify degree/sign/strength and group membership after the complete mask; report changed endpoint geometry separately from edge-carried offsets. Each accepted complete mask needs an unweighted topology certificate (changed reciprocal-pair count is sufficient; an unchanged count is inconclusive). A weighted certificate alone cannot establish unweighted nonisomorphism.

Response matching minimizes the weight-scaled squared difference of complete **absolute ReLU source-response vectors**, concatenating the gray and development trajectories with equal per-clip weight. This includes DC forcing: evoked-only matching can miss unequal gray responses. Evoked vectors above define the nontrivial-dose diagnostic, not a substitute for the absolute current-forcing identity. All arms use the same legal pool, candidate-search ceiling, edited-group composition, and frozen dose. Geometry controls must additionally balance source separation, changed endpoint lengths/directions and spatial boundary positions; activity controls balance source evoked magnitudes without vector correspondence. Shuffling occurs within source type and spatial bins and is fixed before confirmation. Publish overlap diagnostics for the complete masks, not only marginal candidate lists. Predefine binning and feasible balance tolerances from graph geometry and development variability before outcome comparisons. If fair overlap cannot be achieved without almost identical masks, the discriminating experiment is infeasible.

Static group enumeration proves only structural support. Response/geometry common support and informative-dose existence require the bounded development pilot **after guidance/research gates**. Startup may accept an executable plan with explicit pilot stop conditions; it cannot claim this empirical feasibility already passed. Requiring successful response-matching results before guidance would execute the experiment out of order. The pilot is P2 development evidence, and failure returns to the earliest affected design stage.

## Operational reference and uncertainty

The source's documented sensory-noise augmentation supplies a candidate operational reference, subject to exact code/config verification. It does not establish perceptual or biological equivalence. Use the same output normalization, eligible-reference rule and scene aggregation as null discrepancy q. Freeze the augmentation location/order, RNG seeds, development checkpoint/clip identities and noise repeats before calibration. Report the distribution of per-checkpoint and per-scene values and the resulting delta_noise in both normalized and absolute output units.

Do not treat a development-estimated delta_noise as exact. In every uncertainty replicate, resample development scene clusters and noise-draw identities to recompute the calibration statistic; independently resample confirmation scene clusters and mask families, maintaining original/null/checkpoint pairing. For the fixed receiving-checkpoint panel, report finite-panel uncertainty conditional on those distinct solutions. Any model-resampled sensitivity analysis addresses this particular ensemble, not independent initializations or biological populations. Compute E1 differences q-delta_noise and E2 error/delta_noise within each replicate. A calibration lower confidence bound reaching the predeclared numerical eligibility floor blocks ratio-based inference.

The exact repeat count and precision plan are frozen from measured cost and development variance before confirmation. Report inadequate precision as failure of the proposed evidence plan. Do not reinterpret an unresolved equivalence interval as successful preservation.

## E2 scope, half-margin target, and multiplicity

Retain the frozen reference-gated recurrence as a **continuous discrepancy forecast**, with the original query trajectory explicitly included in its inference cost. Set G=1[v>0], hence the zero subgradient at exact zero. Report exact-zero and near-zero reference-state fractions and gate-crossing diagnostics only after forecasts are sealed. For receiving checkpoints instantiate A and A' from that checkpoint's own frozen weights under the verified shared-group mapping. Pair original/null runs using the exact same stored initial state and inputs.

The proposed upper confidence bound MAE/delta_noise <=0.5 means average forecast error resolves half of the operational preservation margin. This is a continuous-resolution design target; it implies neither individual decision reliability nor useful classification at q=delta_noise. Threshold confusion matrices and ambiguous cases are descriptive. This explicitly replaces v1's unfinished useful-threshold-classification requirement in the **unaccepted** plan; independent review must decide whether E1/E3 plus a continuous E2 diagnostic are sufficient for the scientific contribution. No classification claim may be inferred from meeting the MAE target.

Freeze a finite inferential family before confirmation: every prespecified E1 preservation/control-separation contrast for each mandatory input/transfer arm, E2's half-margin error gate, and each primary E2 comparator improvement. Use one-sided Bonferroni-adjusted bootstrap bounds at 1-0.05/K for K directional claims, with paired two-sided bounds where direction is not prespecified. The comparator list is exactly zero-divergence, calibration median, development-output transfer, forcing L2, forcing infinity, structural/geometry regression and magnitude regression. Distinct predeclared ablations remain secondary unless included in K. Report unadjusted estimates alongside adjusted bounds. Freeze K and all conditions before opening confirmation outcomes; failed comparisons cannot be removed from the family.

Bootstrapping is an uncertainty approximation, not an exact guarantee; development-based simulation must check conservative precision under the finite available scene/mask counts before confirmation. The inference plan needs implementation and review before acceptance. If required precision does not fit the bounded resource envelope, revise the plan rather than alter the operational scale or silently lower a result target.
