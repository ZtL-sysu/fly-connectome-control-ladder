## Question and estimands

Does an observed small connectome–null performance gap reflect task-relevant representational similarity, a poorly fitted readout, compensation during network learning, or imprecise measurement? These are different hypotheses. Competence is an eligibility check for a useful task comparison, not a sufficient cause of topology sensitivity.

Keep the official TopoSens edge-carried parameter assignment for the primary replication. It is disclosed in that paper §4.2. Endpoint-consistent assignments, if implemented, are a distinct estimand and a sensitivity analysis. Keep from-scratch and pretrained models separate. Never count a copied biological run once per mask as independent evidence.

## Mechanism repair: separate information, readout, and adaptation

For pooled features h, readout W,b and target y, let a fixed-parameter graph intervention produce d = W(h_null−h_bio). With e = Wh_bio+b−y, the exact squared-error change is mean(2 e·d + ||d||²), with the same normalization as the implemented MSE. Large latent displacement can be hidden by projection through W, while residual alignment can cancel its positive quadratic term. Neither low competence nor latent displacement alone predicts the sign of the task effect. This identity is standard algebra, not a new theorem or contribution.

Three crossed assays localize the bottleneck: (i) official joint-training decoder, (ii) validation-regularized ridge probe on each frozen feature set, (iii) frozen-readout/frozen-parameter graph intervention before any adaptation. Separately retraining the graph measures adaptation capacity. A probe rescue is evidence about the specified readout family; it is not evidence that the recurrent network itself learned more, nor a claim that all information is linearly accessible.

Potential contribution is an independently confirmed empirical dissociation in a real connectome visual model, together with a train/validation-fitted predictor of intervention consequences. Standard controls, longer training, ridge fitting, and the algebra do not constitute novelty independently. Existing Nature2024, TopoSens, Structure Alone, FlyHack and boundary-null work must be distinguished by actual results.

## Assay and inference rules

- Input permutation is an inference-time marginal-preserving sensory-dependence positive control. It does not measure sensitivity to subtle topology changes. Use fixed nonidentity permutations and report its effect separately.
- A complete computational isomorphism is an implementation sanity check. Synchronize graph endpoints, all node/edge parameters and sharing indices, state, stimulus mappings, readout columns, optimizer state when comparing trajectories, and stochastic draws. Compare logits/features after undoing mapping; never permute only adjacency.
- Train seed and null-mask seed are different axes. Confirmation uses fresh seeds and masks; bio is shared across masks within seed. The primary response per training seed averages that seed's mask effects; report mask variability separately and use a crossed random-effects sensitivity analysis. Do not bootstrap stimulus frames as independent networks.
- Selection uses train/validation only. Define the competent horizon as the earliest fixed-grid checkpoint meeting the preregistered validation skill and circular-error criteria; use the same rule for every graph. A fixed common-horizon comparison is primary for learning-regime interactions; graph-specific selection is secondary because optimization time differs.
- Pilot estimates costs/variance and can reject directions; it cannot establish generalization, equivalence or a manuscript claim. Confirmation conditions, equivalence margins and sample size must be frozen before opening its test.
