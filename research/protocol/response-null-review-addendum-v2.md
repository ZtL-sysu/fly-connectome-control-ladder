## Targeted verdict

**The former E2 leakage/data-flow blocker is substantially repaired on paper.** The proposed predictor is a frozen reference-gated linearization that uses the original query trajectory after the mask is frozen, but never reads the query's actual rewired trajectory, output, label, or loss before forecasting. The actual rewired run is sealed until forecasts are written. This is a legitimate reference-trajectory-assisted forecast, with explicit inference cost; it must not be described as training-only prediction or zero-query-compute.

**E2 is now suitable for conditional inclusion in sequential guidance planning, not yet an accepted primary claim.** The fixed recurrence is a plausible mechanistic forecast and the document explicitly disclaims algorithmic novelty. The primary “95% upper bound of normalized MAE <= 0.5 noise units” is interpretable as a prospective resolution target, but its practical usefulness is not established by the number 0.5 alone. It needs a decision-level threshold criterion, common-scale calibration details, and simultaneous comparison inference before confirmation. None of those repairs supplies positive prediction evidence.

**The An/Liu abstract-level novelty uncertainty is repaired; the Zhou–Hasler implementation boundary is now directly audited.** The source screen gives methods-level distinctions from An and Liu, and the new immutable-commit audit of Zhou–Hasler's official repository confirms ordinary random degree-preserving swaps followed by 250k-iteration training from scratch and response-RDM evaluation, not E's frozen response-conditioned intervention. Thus a prior-art block based only on abstract-level uncertainty is no longer justified for sequential planning. The bioRxiv full text remains unavailable (HTTP 429), however, and the inspected code cannot prove that an unbundled manuscript supplement contains no additional analysis. The novelty delta is better grounded but remains scoped to the audited implementation and retrieved methods, not cleared as a universal “first” claim.

## E2 predictor and leakage audit

### What is now adequately specified

- Target `q` is the paired, same-checkpoint null-vs-original trained-decoder flow-output RMS normalized by original-output RMS, aggregated within clip and then equally across clips within scene. The `1e-6` floor and ineligible-reference rule are explicit.
- Permitted forecast inputs are the frozen mask/checkpoint/config, unlabeled query images, and original-model query trajectory/output. Actual null query outputs, query labels/losses, and confirmation outcome files are excluded.
- The recurrence `z[t+1] = (I-D) z[t] + D A' G[t] z[t] + D (A'-A) ReLU(v[t])`, with `G[t] = diag(1[v[t] > 0])`, is the expected first-order state perturbation about the original trajectory, retaining the rewired operator in feedback. Decoding `v[t]+z[t]` through the frozen nonlinear decoder is a coherent way to forecast output discrepancy. It is exact only while the two trajectories remain in the same ReLU regions, which the spec acknowledges.
- Mask selection is frozen before the original query trajectory is made available; confirmation labels and null outputs are sealed until forecasts are saved. The proposed sentinel isolation check is useful and should remain in the plan.
- The spec labels the predictor a baseline/mechanism diagnostic, not a novel algorithm, and forbids replacing a failed fixed predictor post hoc with an outcome-trained predictor.

### Residual E2 blockers before it can be a binding guidance claim

1. **Operational meaning of the 0.5-unit error target.** A clustered upper confidence bound on scene-mean `|q_hat-q|/delta_noise <= 0.5` is a clear scale-relative forecast-accuracy gate, but the half-unit choice is not derived from an application decision. It can be defended as “forecast uncertainty is at most half the operational preservation margin,” which aims to resolve whether `q` lies on either side of that margin. Before confirmation, state that rationale and preregister a threshold-decision requirement (for example, minimum sensitivity/specificity or balanced accuracy at `q=delta_noise`, with an explicit rule for ambiguous cases). If no decision use is needed, drop the claim that E2 usefully classifies preservation and limit it to continuous forecast accuracy. Do not choose the operating point from confirmation results.
2. **Propagate calibration uncertainty.** Freeze and document exactly how per-model/per-clip .08-noise reference values become one `delta_noise`: same output normalization, clip/scene weighting, eligible set, noise seeds, and model weighting as the null `q` scale. The clustered interval for E2 must account for uncertainty in this development-estimated scale, not treat a noisy calibration median as exact. Retain the source-verification of noise injection/clipping semantics required by v1.
3. **Define simultaneous comparator testing.** “Improvement interval excluding zero against every comparator” entails multiple paired comparisons. Either prespecify familywise/simultaneous intervals or nominate one primary comparator and label the rest secondary. Keep the finite comparator list and calibration-only fitting/sealing rules as written; no generator-ID shortcut.
4. **ReLU boundary convention.** Specify `G[t]` at exact zero (the written indicator implies the zero subgradient) and report how often query reference states lie exactly/near zero. The forecast remains a first-order approximation if perturbations cross activation regions; do not state an error guarantee from the recurrence. The holdout test, including its failures, is the evidence.
5. **Mask/checkpoint-specific operator and pairing.** For transferred masks, instantiate `A'` from each receiving checkpoint's own frozen parameters under verified shared parameter-group semantics. Pair null and original from the same explicit initial state and input timing. Keep actual per-model matching and transferred-mask estimands separate.

The “test-time input” concern is therefore resolved only under the explicit forecast-query protocol in the new spec. The model's original output is an allowed query-time side signal, so the paper must disclose that assumption and its cost. Forecasts cannot be presented as available before running the original reference model.

## E1/E3 sufficiency and remaining planning conditions

E1/E3 can carry the scientific story **provided** the pinned Zhou–Hasler implementation is represented accurately and response-matched masks beat matched controls on genuine confirmation inputs/models. The new repository audit is sufficient to establish that the inspected E5 code is retrained, response-unconditioned degree swapping; it is not proof that no unbundled paper/supplement analysis exists. An and Liu's methods and the inspected Zhou implementation do not themselves close E's exact no-refit response-conditioned construction gap. If response matching yields only silent/near-zero mass, computational isomorphisms, development-only preservation, or equal preservation across adequately resolved controls, the main contribution fails regardless of E2 forecast accuracy.

Before guidance can mark the planning package complete, require these still-open conditions:

1. **Zhou–Hasler novelty disposition:** incorporate the pinned-code audit as affirmative evidence about the public implementation: ordinary random degree-preserving swaps, 250k from-scratch null training, and response-RDM comparisons; no response-conditioned selection or acute frozen intervention was found in inspected files. Record that full paper retrieval remains unavailable, and scope any novelty statement to the inspected implementation and evidence. Do not turn missing full text into a claim that the paper or an unbundled supplement has no additional analysis.
2. **Common support and informative dose:** statically enumerate exact legal swaps and show that response, constrained-random, geometry, magnitude-only, and shuffled controls overlap on changed active mass, geometry, group composition, and declared intervention dose. Supply a per-mask topology certificate plan. No scientific run if this feasibility gate fails.
3. **Noise-margin and dose calibration:** verify the source's σ=.08 noise augmentation semantics; freeze `delta_noise`, denominator, aggregation, near-zero exclusions, noise seeds, dose grid and selection rule using development/calibration data only. Report all dose-grid values. Do not pick the margin to make a null pass, or select a dose by looking at confirmation outcomes.
4. **Forecast protocol freeze:** add the E2 repairs above, freeze the model/scene/mask manifest, predictor/comparator code and hashes before confirmation, and preserve all failed masks. Prediction files must be sealed before any actual-null query output is produced or joined.
5. **Resource gate remains unpassed:** remote profile is pending. Obtain measured forward, decoder-restore, and proposal-search cost/peak memory under the already bounded, label-free engineering profile. No result about affordability follows from the 19-frame shape estimate or the 50-model archive. If the forecast upper-bound or E1 precision target cannot fit the stated budget, return to design; do not weaken the margin or repeatedly expand masks.
6. **Scope and inference:** retain separate within-model matched and cross-model transferred arms. Treat the 50 checkpoints as distinct trained solutions with common initialization/task seed, not independent biographs or independent initialization seeds. Use model/scene/mask clustering and finite-ensemble language.
