# Candidate E paired-edge-set geometry correction v2

Status: prospective correction following actual static evidence; not accepted scientific guidance. Preserve construction-v1, structural-support-report.json and block-geometry-support-v2.json. No response feature or task outcome was used in these screens.

## Observed structural evidence

Exact source constructors at the pinned Flyvis commit compile 45,669 nodes and 1,513,231 edges, with no parallel original arcs, 12,380 original self-loops, 604 typepairs and 2,355 complete syn-count groups. A 1,000-swap source-only sample conserves degree, self-loops and per-target complete-group counts exactly. Its reciprocal-pair count changes from230258 to229604, certifying unweighted nonisomorphism. Group IDs in this static export are label-derived and are not raw checkpoint parameter-array indices; runtime map verification remains required.

The v1 exact-displacement variant is unsupported by the bounded sample: none of the inspected eight-edge blocks had two legal complete matchings with the same exact new-displacement multiset. Do not adopt that version or claim exact geometry support. The screen is not an impossibility proof for the whole graph.

A second, graph-only 300-block screen uses this explicitly approximate signature: joint histogram of new-edge hex distance bin, six direction sector and source boundary-radius bin; plus histogram of signed source-pair displacement distance/direction. Distance boundaries are2,4,8,16,32,64 hex steps; boundary means source radius>=8. Of296 nonloop blocks,278 have at least two legal matchings in a common stratum and164 have at least four. This is structural support in sampled blocks; it proves neither whole-mask support at an evoked dose nor activity/functional benefit.

## Proposed corrected construction

Use the v1 same-edited-edge perfect-matching construction, replacing exact displacement strata by the specific joint binned signature above. Choose the common stratum graph-only: greatest number of legal matchings, breaking ties lexicographically. Require at least four distinct complete matchings before accepting a block into the shared support. Shuffle/order blocks with a fixed graph-only RNG. All arms retain identical original edited edges, original source/target sets, shared groups, degree and evoked mass; all satisfy the same binned signature.

**Residual geometry is an explicit nuisance.** Report actual new-edge lengths, directions, source separations and their source-boundary associations for complete masks. Include a strong geometry arm that minimizes the exact sum of squared source separations within the shared stratum, with deterministic tie-breaking, as well as constrained-random, magnitude and shuffled-response arms. Geometry minimization uses no responses. If response matching merely exploits shorter within-bin separations, this geometry arm should resolve that explanation; superiority to the geometry arm remains a primary gate.

Before opening functional confirmation, assess the complete-mask imbalance with fixed thresholds learned from graph-only variability, and retain exact-geometry covariates in the prespecified secondary residual analysis. A significant covariate adjustment cannot rescue failed primary balance or failed geometry-control separation. Inadequate overlap returns to design; do not describe binned geometry as exact physical equivalence or use it for a causal claim that response correspondence is the sole changing property.

For response construction, the blockwise objective proposes up to four complete-mask candidates. Their final selection uses the full-mask aggregate forcing in protocol-closure-v4, including shared targets and gray/development clips. Keep candidate budgets symmetric and finite; define the deterministic top-candidate combination rule before the pilot. Merely summing blockwise scores is not the final objective. This remaining code-level rule and whole-mask geometry tolerances need closure before startup acceptance.

The static sample supports continuing this binned variant's implementation design. It does not establish an active1–20% dose, competent teacher, stable noise reference, successful response matching, checkpoint transfer, resource timing, or a manuscript contribution. Those retain their ordered engineering/pilot/confirmation gates.
