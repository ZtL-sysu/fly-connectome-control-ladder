## Prospective resolution and effect rules

The function-preservation scale must be fixed from a reference independent of proposed-null success. Use the source model's documented sensory augmentation: Gaussian white input noise with standard deviation .08 on the [0,1] input range (metadata and original Methods), with clipping/rendering semantics explicitly taken from source. On fixed development clips and predeclared noise RNG seeds, define each model's noise-reference normalized flow-output RMS. Freeze a robust aggregate (median across the designated development models and noise draws) as delta_noise before inspecting confirmation null outcomes. This is an operational robustness scale; it is not biological equivalence or universal perceptual tolerance. Report the absolute flow units and normalization denominator, and flag a near-zero reference output/near-zero noise response as ineligible rather than inflating ratios.

Select intervention dose on development only from the finite active-weighted-dose grid {.01,.025,.05,.10,.20}. Choose the smallest feasible common-support dose at which the constrained-random **and geometry-matched** control divergences exceed delta_noise, with a development interval resolving that direction. Freeze dose and all generator choices before confirmation. If no such dose exists, the assay does not discriminate these controls within budget and E1 fails; do not choose a different margin to make it informative. This grid is an intervention sweep, not a promised performance gain. Also report edge fraction, active mass, geometric shift and topology certificate so a small numerical dose cannot conceal trivial editing.

`minimum`: correct full source model, legal non-isomorphic masks, nontrivial active mass, actual CUDA feasibility, and a development-only response-matching effect over structural controls at common support. This only retains a candidate; it is insufficient to draft.

`expected_strong`: on prospectively frozen confirmation scenes/mask families, response-matched null output discrepancy has a one-sided seed/model-clustered 95% upper bound below delta_noise, while the geometry- and constrained-random controls have lower bounds above delta_noise at the same frozen dose. Their paired difference must also resolve zero in the predicted direction. Report magnitude-only and shuffled-correspondence ablations and explain any failure to separate them. At least one withheld-model transfer arm and independent procedural/naturalistic input arm must confirm the mechanism. This is a strict separation/equivalence criterion in a source-calibrated unit, not a desired headline gain.

For E2, retain a prediction claim only if a frozen predictor/linear-response diagnostic improves held-out error over **all** stated structural, activity, geometry and development-output comparators with clustered uncertainty resolving improvement, and predicts which functional comparisons fall on either side of the frozen delta_noise threshold with useful precision. A complete numeric forecast-error margin and source-response-coverage estimator are still missing: E2 is not yet accepted as a binding main claim. Either specify them before guidance, or make E2 descriptive and obtain a new scientific review of E1/E3's sufficiency. Do not silently drop E2 after it fails.

`failure`: no eligible noise-reference scale; no competent reference; no common legal dose; equivalence only in development; no superiority to geometry/activity controls; no topology certificate; insufficient confirmation precision within budget; or full-text prior art already establishes the same mechanism/construction/evidence. Return to CCFA design rather than draft.

## Baselines and actual assets

- Strong direct model baseline: official Nature2024 flyvis network **and trained DecoderGAVP**, actual50-checkpoint archive acquired with publisher SHA256; pair each null with its own checkpoint and readout. Do not substitute a new weak linear decoder for the primary naturalistic experiment.
- Closest direct null baseline: TopoSens official directed double-edge-swap generator, adapted to explicit type/sign/effective-weight constraints required for the new estimand; also reproduce unconstrained degree-null separately for context. Disclose semantic changes rather than call it an exact rerun.
- Technique-family baselines: geometry/weight/strength-preserving graph controls; feature-guided rewiring and task-aware compression are prior art. The methods/code availability of the closest new bioRxiv/arXiv studies is under full-text verification. No claim of having rerun them yet.
- Simple baselines: zero/constant/input-only motion prediction for labelled development competence; unchanged model/sham and full computational-isomorphism negative control. Input identity permutation is an input-dependence check, not power calibration for subtle topology effects.
- Data: direct Sintel training-sample access verified. Official TEST images are publicly downloadable, but their full archive has not yet been acquired. Original source validation/fold material is exposed to checkpoint selection. Record scene identities and source fold before use; no official leaderboard accuracy claim.

## Implementation and finite budget

Before any scientific forward pass, resource-profile and source compatibility must pass: exact full graph, CUDA placement, decoder restoration, model/config hashes and complete failure artifacts. The pending remote profile uses only constant inputs and no optimizer/labels; it is engineering evidence, not a pilot result.

Scientific pilot after guidance/research gates: <=4 cumulative GPU-hours, at most two sequential exp-4090 tasks. Predeclare two development checkpoint IDs and at most two null-mask RNG families per generator, the dose grid above, <=8 development 19-frame clips, no confirmation scenes/model IDs. No trainable weights, decoder fitting or optimizer search. Proposal budget <=200,000 legal pair candidates per construction arm and <=5 dose evaluations; record all rejected/accepted trials. If exact-weight classes yield insufficient nontrivial matching or geometry common support, stop immediately. Workload cost and clip resampling length must be measured; 19 source frames can become more integration steps after50Hz resampling.

Provisional confirmation cap: <=32 additional single-GPU hours, inference only; no hidden retraining. Use20 withheld trained-model identities, three independent mask RNG families per arm, and scene-level aggregation with nested mask uncertainty. Report that models share initialization and the connectome. Perform a finite-population ensemble analysis and mask/scene uncertainty; do not label this20 independent-init-seed evidence. Pilot variance supplies conservative precision planning; if the required equivalence precision does not fit32h, return to design instead of reducing it. Track pilot+confirmation cumulative usage in one ledger. Any proposed extra campaign needs explicit resource reasoning within user authorization; no automatic reset.

Search choices are finite: one source-response distance definition, exact parameter-compatible candidate pool, one geometry stratification and magnitude-only/shuffled ablations. Hyperparameters must be frozen on development before confirmation. An unchanged failed candidate is not resubmitted with new seeds indefinitely.
