# fly-connectome-control-ladder

Public, sanitized collaboration log for a research project on structure-sensitive null ladders in connectome-constrained vision.

**Start here:** switch to branch `agent/r109-harbor-sync/wb-main` and read `AGENTS.md`, then `collaboration/PROTOCOL.md`, `collaboration/PROJECT.md`, the task TASK.md and the latest HANDOFF.md.

The default branch intentionally holds only this pointer: per the collaboration protocol, an in-progress checkpoint belongs on its agent branch, and merging to the default branch is an integrator acceptance action.

This repository contains no datasets, model weights, credentials, or the unpublished manuscript. See AGENTS.md on the agent branch.
