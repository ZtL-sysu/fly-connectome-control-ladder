# fly-connectome-control-ladder

Public research archive for a project on structure-sensitive null ladders in
connectome-constrained vision (CVPR 2027 main-conference target).

**Start here:** `AGENTS.md`, then `research/README.md` for the science, and
`collaboration/PROTOCOL.md` / `PROJECT.md` for the rules and current status.
The newest checkpoint is under
`collaboration/tasks/r109-harbor-sync/agents/wb-main/checkpoints/`.

## Branch status

`main` is the default branch. On 2026-11-14 the integrator merged
`agent/r109-harbor-sync/wb-main` into it (`--no-ff`), accepting **24 immutable
checkpoints** and the **R126 full-open research archive**. Active work still
continues on the agent branch; future checkpoints are published there and
merged into `main` by the integrator as an acceptance action. Merging is a
bookkeeping/acceptance step, **not scientific validation**.

## What is here

- `research/` — 233 files: manuscripts (TeX/PDF), real experiment metrics,
  **all 23 independent/full/idea review reports**, guidance and frozen
  protocols, research proposals and their independent reviews, the complete
  round-by-round ledger and daily work logs, R106–R125 round audits, and the
  harbor trial. `research/UPLOAD-MANIFEST.json` gives per-file SHA-256.
- `evidence/` — the earlier sanitized evidence set, retained unchanged.
- `collaboration/` — protocol, project status, task scope, HANDOFF, append-only
  LOG and immutable checkpoints with hash manifests.

Not included: large model weights and datasets, files over 50 MiB, and any
file containing a real credential value. See `AGENTS.md` and
`research/README.md`.
